autocomplete-sh / acsh

Command Your Terminal With Context

autocomplete-sh, or acsh for short, is an AI-assisted terminal autocomplete library and CLI for Bash and Zsh. It is now maintained as an independent fork at github.com/kmal808/autocomplete-sh.

Open Repo Latest Releases

Install

curl -fsSL https://raw.githubusercontent.com/kmal808/autocomplete-sh/main/docs/install.sh | sh

Installs the latest release binary, adds the acsh alias, and sources the right shell adapter in your rc file.

Configure

export OPENAI_API_KEY='your-key'
autocomplete config init
autocomplete doctor

Config is stored in ~/Library/Application Support/autocomplete-sh/config.json on macOS unless you override it with AUTOCOMPLETE_CONFIG.

Use

autocomplete complete --shell zsh --line "git sta" --cwd "$PWD"
acsh prompt --shell zsh --line "ffmpeg # shrink for email" --cwd "$PWD"

The shell adapters collect history, recent files, and command help, then ask the CLI for suggestions.

What Changed

This fork no longer depends on the original shell-script-only architecture. The current codebase is a Go library plus CLI, with thin Bash and Zsh adapters, OpenAI and Ollama providers, file-backed caching, and testable release artifacts.

Fork provenance is preserved in the repository license and NOTICE file.
